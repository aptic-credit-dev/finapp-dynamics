# Shared-Service Ownership

Exactly one authoritative implementation of each shared service. Consume via DI token/contract; never duplicate.

| Shared service | Owner module | Consumed via | Notes |
|---|---|---|---|
| Tenant resolution / tenancy | m01-tenant | tenant context, composite FKs | 1 tenants table; global control plane |
| Authentication | m02-identity | auth guards | login_attempts is pre-auth (global) |
| Authorization / RBAC / permissions | m02-identity | `AUTHZ` token | 1 permission catalogue seed |
| Audit | m03-audit | `AUDIT` token | 1 code registry; append-only; unregistered codes fail CI |
| Status engine | m06-workflow | contract | state machines per entity |
| Workflow / BPM | m06-workflow | contract | configurable, versioned |
| SLA / timers | m06-workflow | contract | business calendars |
| Timeline / activity | m06-workflow | contract | structured + free-text |
| Transactional outbox | m06-workflow | `OUTBOX` token | **the only** event-delivery path |
| Rules engine | m07-rules | contract | versioned, auditable |
| Notifications | m08-notify | contract | email/SMS/WhatsApp-ready/in-app |
| Escalation | m08-notify | contract | triggers on SLA/status |
| Documents | m09-docs | contract | classified, linked, versioned |
| Idempotency | m06-workflow | idempotency store | high-risk actions |
| Platform metadata | m30-platform | contract | governed platform-metadata catalog (Stage 6A) |
| Platform configuration | m30-platform | contract | typed config definitions + values + history; secret-bearing settings hold a secret reference only |
| Feature flags | m30-platform | contract | ONE feature-flag engine (definitions/assignments/evaluation); a flag never bypasses RBAC; m04-admin CONSUMES it (GAP-5, ADR-115) |
| Secrets | platform (m30) | secret references | m30 owns the secret-reference SEAM only (opaque secretref:, no raw/encrypted secret VALUE); real secret/key management = m41-security (ADR-116) |
| Design-time authoring (Workflow/BPM/Rules/Forms Studio) | m31-studio | contract | DESIGN-TIME only (author/validate/version/review/publish/bind); the runtime engines stay canonical — m31 compiles/binds designs to m06 workflow + m07 rules, never a second engine, no runtime execution (Stage 6B, ADR-117) |
| Reusable forms / form schemas | m31-studio | contract | canonical owner of reusable DECLARATIVE form/schema DEFINITIONS (typed fields, versioned, published-immutable, no executable code); FORM DEFINITION ≠ BUSINESS RECORD — submitted records stay domain-owned, m12 questionnaires stay m12 (Stage 6B, ADR-117) |
| Entitlements / quotas | m39-saas | contract | plan → capability → flag order |
| Usage metering / billing | m39-saas | contract | idempotent usage; immutable invoices |
| Connector marketplace (listings, installations, consent, upgrades) | m34-marketplace | contract | governed catalog/installation layer OVER m33 connectors — consumes m33 by contract (opaque connector refs, fail-closed ConnectorRegistryPort), no duplicate connector engine, never executes a connector; consent + publication + upgrade are human-governed controlled actions (maker-checker, AI never consents, consent revocable); NOT a secrets manager (install secrets = opaque secretref: via the m30 seam, zero values, m41 deferred); marketplace_* prefix (Stage 6D-2, ADR-121) |
| Public APIs & developer portal (apps, API credentials, products, subscriptions) | m35-devportal | contract | governed developer portal + API-gateway FACADE over the platform — a product exposes only allow-listed operations, each carrying the m02 permission it requires, so public exposure NEVER bypasses m02 RBAC or m01 tenancy; consumes m34/m33 by contract (opaque source refs, fail-closed CatalogSourcePort) + m39 quotas behind a fail-closed UsageQuotaPort (m39 unbuilt -> deny), no duplicate connector/marketplace/quota engine; NOT a secrets manager (API credentials = one-way sha256: hash XOR opaque secretref: via the m30 seam, zero plaintext columns, m41 deferred); credential issuance/rotation/revocation are human-governed (AI never issues), product publication + subscription approval are maker-checker/SoD controlled actions (AI never approves, published-immutable); devportal_* prefix (Stage 6D-3, ADR-122) |
| Webhooks & event streaming (endpoints, subscriptions, delivery, streams/cursors) | m36-events | contract | governed OUTBOUND fan-out over the platform's domain events — m06 owns THE ONE outbox/event-delivery path, m36 owns NONE: its RelayService consumes events via a fail-closed EventSourcePort fed by the m06 dispatcher and records delivery, NO second outbox/delivery path; webhook delivery is EXTERNAL EGRESS = framework-only behind a fail-closed WebhookDeliveryPort (no production network/provider; unavailable -> durable BLOCKED; https public URLs only, SSRF allow-listed); NOT a secrets manager (endpoint signing secret = opaque secretref: via the m30 seam, zero secret value columns, m41 deferred); endpoint activation is a human-governed controlled action (maker-checker/SoD, AI never approves, approved url/key immutable); a subscription/stream may only target a REGISTERED event family, a subscriber sees only its own tenant's events (FORCE-RLS), delivery is idempotent; webhook_/eventstream_/events_ prefixes (Stage 6D-4, ADR-123) |
| Integration governance / QA / release (artifacts, environments, releases, QA gates, evidence) | m37-govrelease | contract | governed promotion of an integration artifact (an m33 connector, m34 listing, m35 API product, m36 webhook/stream) through QA gates to a released state per environment — RECORDS + GOVERNS the release decision + QA evidence, EXECUTES no release (runtime stays with the owning module); consumes m33/m34/m35/m36 by contract (opaque artifact refs, fail-closed ArtifactRegistryPort, reads no owning-module table, no duplicate engine); a release is human-governed (maker-checker/SoD over a passing QA evidence gate, AI never approves/releases, released-immutable, one released per artifact/environment); NOT a secrets manager (a release signature = opaque secretref: via the m30 seam, zero secret value columns, m41 deferred); owns govrelease.lifecycle + a DISTINCT GOVRELEASE_ audit prefix (not m33's INTEGRATION_); one m06 outbox; govrelease_ prefix; a HARD dependency of m42-certification (Stage 6D-5, ADR-124) |
| Scheduler / automation / extensions (recurring schedules, automation definitions + steps, execution evidence, extension points/installations) | m38-automation | contract | governed scheduler/automation/extension framework — m06 owns THE durable one-shot timer + SLA + workflow runtime + THE ONE outbox, m38 owns NONE: it owns recurring-SCHEDULE + automation DEFINITIONS and execution EVIDENCE and COMPOSES an m06 timer per occurrence via a fail-closed TimerSchedulerPort, computing next_run_at with a GOVERNED restricted recurrence parser (bounded vocab hourly/daily/weekly + every:<seconds>, 60s frequency floor — NO OS cron/shell), NO second timer/scheduler/workflow engine; execution is FRAMEWORK-ONLY through a fail-closed CapabilityInvokerPort (default Unavailable -> a durable BLOCKED run); a step/point references a REGISTERED capability (opaque ref) + carries a 3-segment m02 permission — NO eval/Function/child_process/shell/arbitrary SQL/uploaded code (extensions = registered points with trust tiers + isolation, published-immutable); automation ORCHESTRATES while owning modules ENFORCE — it never bypasses m02/m21-m22/m33/m34/m35/m36/m37, never auto-posts/releases/consents, and CONSUMES an already-approved opaque reference (it cannot fabricate a human approval); activation + extension publish are human maker-checker/SoD controlled actions (AI/system/automation never self-approve); FORCE-RLS + composite tenant-safe FKs, platform scope requires automation.control.administer; NOT a secrets manager (config = opaque secretref: via the m30 seam, zero secret value columns, m41 deferred); owns automation.lifecycle + extension.lifecycle + the AUTOMATION_/EXTENSION_ audit prefixes; one m06 outbox; automation_/extension_ prefixes (Stage 6E, ADR-125) |
| Integration foundation (connector SDK/registry, connections, runtime) | m33-integration | contract | FRAMEWORK-ONLY (fail-closed runtime, deterministic doubles, no production egress); NOT a secrets manager (connections hold opaque secretref: pointers via the m30 seam, zero secret values, real key mgmt = m41); registered capabilities only (no arbitrary code); uses connector_* prefix — m23-finance-integration keeps its finance-specific integration_* tables; implements m31's IntegrationCapabilityCatalogPort (Stage 6D-1, ADR-120) |
| Reporting / analytics | m32-analytics | contract | canonical enterprise reporting/analytics BUILDER (semantic datasets, metrics/KPIs, reports, dashboards, exports, schedules); DERIVED/READ layer — source of truth stays with each source module; governed semantic query (no arbitrary SQL); entitlement intersection (aggregation grants no access); implements the M28 ExecutiveAnalyticsPort; money is bigint minor/decimal/bps (no float). m10-report (Stage 2 placeholder, never built) is subsumed — no second reporting engine (Stage 6C, ADR-119) |
| AI gateway | m24-ai-foundation | contract | provider abstraction, registries |
| Security control plane | m41-security | contract | posture over RBAC; never replaces it |

## Verification (reference baseline)
0 outbox implementations outside m06 · 1 tenants table (m01) · 1 audit registry (m03). Any new module must be
checked against this table before it is allowed to ship.
